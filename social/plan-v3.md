## What changed in v3

v3 keeps the proven v2 publishing shape (same cadence, same 12 reel days, same plain-language voice)
and refreshes the copy around the features that shipped since:

- **Synced website builder** - the site preview builds itself from the live Google profile and stays in sync (Day 12, Day 27 reel).
- **Flat $19 domain with local TLDs** - one price, registered in the trader's name, first 90 days of hosting free (Day 12, Day 15, Day 27).
- **GBP audit sub-scores** - profile completeness, reviews, activity and photos, each scored out of 100 (Day 10, Day 16 reel, Day 22 reel).
- **Review asks by WhatsApp, SMS or link** - the trader picks the channel, the customer gets the easiest one (Day 4, Day 5 reel, Day 24, Day 28 reel).
- **No-WhatsApp onboarding** - email or Google sign-in, quick-post link, SMS or link review asks (Day 24, Day 26 reel).
- **Trade landing pages and free guides** - plumbers, electricians, roofers, locksmiths, HVAC, plus service-area businesses (Day 19).

All 12 reels were regenerated from scratch for v3, so the finished MP4s match the v3 captions word for word.

## Reel production

All 12 reels share one deterministic pipeline, so any day can be rebuilt frame for frame:

```bash
node reel/build-reels.mjs            # writes public/reel-dayNN.html for all 12 reels
node reel/build-reels.mjs 5 8        # ... or rebuild selected days only
node reel/make-reel.mjs 5 8          # render + encode social/day-NN/day-NN-reel.mp4
node reel/preview.mjs 5 2,7,15       # full-res PNG stills for a visual check
node social/scripts/verify-plan-v3.mjs  # re-check xlsx, caption sheets, MP4s and this file
```

Each generated page exposes the contract the renderer relies on: a 1080x1920 canvas `#cv`,
`window.__reel.DURATION`, a deterministic `window.__frameAt(t)` and `window.__reelReady`.
Frames are captured at 30fps with Playwright (parallel workers) and encoded with ffmpeg to H.264 yuv420p,
matching the finished v2 masters.
